# Akte Dokumen

Modul Akte Dokumen mengelola akte notaris dan dokumen hukum koperasi.

## Mengakses Halaman

Klik **Dokumen Legal → Akte Dokumen** di sidebar.

## Daftar Akte

Tabel menampilkan:
- **Judul Akte** dan Nomor Akte
- **Notaris** — Nama notaris pembuat akte
- **Tanggal** — Tanggal akte dibuat
- **No. SK** — Nomor Surat Keputusan (jika ada)
- **File** — Link download jika ada file

## Tambah Akte

1. Klik **Tambah Akte**
2. Isi formulir:
   - **Tanggal** — Tanggal akte
   - **Notaris** — Nama notaris
   - **Nomor Akte** — Nomor akte notaris
   - **Judul Akte** — Judul/nama akte
   - **No. SK** — Nomor SK terkait (opsional)
   - **Tanggal SK** — Tanggal SK (opsional)
   - **Keterangan** — Catatan tambahan (opsional)
   - **File** — Upload file PDF/gambar, maksimal 10MB (opsional)
3. Klik **Tambah Akte**

## Lihat Detail

Klik **⋮** → **Lihat Detail** untuk drawer detail yang menampilkan:
- Informasi lengkap akte (judul, nomor, notaris, tanggal)
- Data SK (nomor dan tanggal)
- Keterangan
- Download dan preview file (PDF atau gambar)
- Metadata (tanggal dibuat/diperbarui)
- Tombol **Edit**

## Edit Akte

1. Klik **⋮** → **Edit** (atau tombol Edit di drawer detail)
2. Ubah data yang diperlukan
3. Upload file baru jika ingin mengganti
4. Klik **Simpan Perubahan**

## Hapus Akte

1. Klik **⋮** → **Hapus**
2. Konfirmasi penghapusan

::: danger
Menghapus akte dokumen bersifat permanen dan tidak dapat dikembalikan.
:::

## Pencarian

Gunakan search bar untuk mencari berdasarkan:
- Judul akte
- Nomor akte
- Nama notaris
- Nomor SK
