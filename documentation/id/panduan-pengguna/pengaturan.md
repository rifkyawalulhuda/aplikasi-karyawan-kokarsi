# Pengaturan

Halaman Pengaturan dapat diakses melalui menu **Pengaturan** di sidebar.

## Tab Umum

Kelola identitas organisasi yang ditampilkan di seluruh aplikasi.

### Logo Organisasi

1. Klik **Ganti Logo**
2. Pilih file gambar (JPG, PNG, WEBP, atau SVG)
3. Logo baru langsung tampil di sidebar dan dokumen kontrak

### Nama Organisasi & Ketua Koperasi

Edit field yang tersedia, klik **Simpan**.

## Tab Profil & Keamanan

Ganti password melalui **Pengaturan → Keamanan**:

1. Masukkan password lama
2. Masukkan password baru (min. 6 karakter)
3. Klik **Simpan Password**

## Tab Tampilan Login (Admin Only)

::: warning Admin Only
Hanya **Master Admin** yang dapat mengakses tab ini.
:::

Kustomisasi halaman login:
- Warna background kiri & kanan
- Gambar background (JPG/PNG/WEBP, max 5MB)
- Opacity overlay
- Warna teks

## Master Data (Admin Only)

**Pengaturan → Master Data** untuk mengelola:
- Lokasi Kerja, Jabatan, Level Jabatan, Departemen
- Status Pajak, Tipe Kontrak
- **Jenis Dokumen** — Tipe dokumen dengan field Kategori (Dokumen Pribadi untuk Dok. Karyawan, Sertifikasi & Ijin untuk modul Sertifikasi & Ijin)

## Template Kontrak (Admin Only)

**Pengaturan → Template Kontrak** untuk mengelola template dokumen PDF kontrak:
- Tambah, edit, dan hapus template kontrak
- Pilih Template Key sesuai posisi karyawan (PKWT/MITRA)
- Kustomisasi narasi/teks dokumen tanpa mengubah kode sistem

Lihat [Template Kontrak](/panduan-pengguna/template-kontrak) untuk panduan lengkap.

## Manajemen User (Admin Only)

**Pengaturan → User** untuk:
- Tambah akun pengelola baru
- Ubah role (Admin / Pengelola Koperasi)
- Reset password, hapus akun

Lihat [Peran & Akses](/referensi/peran-akses) untuk detail perbedaan hak akses.
