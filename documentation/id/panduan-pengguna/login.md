# Login & Akun

## Halaman Login

Buka aplikasi di browser. Anda akan disambut halaman login dengan dua panel:
- **Panel kiri** — informasi dan branding koperasi
- **Panel kanan** — form login

## Cara Login

1. Masukkan **No. Induk Karyawan** (untuk Master Admin) atau **Username** (untuk akun pengelola)
2. Masukkan **Password**
3. Klik tombol **Masuk**

::: info Perbedaan Login
- **Master Admin**: Login menggunakan **No. Induk Karyawan** (contoh: `EMP001`)
- **Pengelola Koperasi**: Login menggunakan **Username** (contoh: `pengelola1`)
:::

## Akun Default

| Peran | Identifier | Password Default |
|-------|-----------|-----------------|
| Master Admin | `EMP001` | `admin123` |
| Pengelola Koperasi | `pengelola1` | `pengelola123` |

::: warning Keamanan
Segera ganti password default setelah login pertama kali melalui **Pengaturan → Keamanan**.
:::

## Ganti Password

1. Klik avatar/nama di pojok kiri bawah sidebar
2. Pilih **Profil**
3. Pergi ke tab **Keamanan**
4. Masukkan password lama dan password baru
5. Klik **Simpan**

## Keluar (Logout)

1. Klik avatar/nama di pojok kiri bawah sidebar
2. Pilih **Keluar**
3. Konfirmasi logout

## Lupa Password

Hubungi Administrator sistem untuk reset password. Tidak ada fitur "lupa password" mandiri karena ini adalah sistem internal.

## Manajemen User (Admin Only)

Administrator dapat mengelola akun pengguna melalui **Pengaturan → User**:
- Tambah akun pengelola baru
- Ubah role (Admin / Pengelola Koperasi)
- Reset password
- Hapus akun

Lihat [Peran & Akses](/referensi/peran-akses) untuk detail perbedaan hak akses.
