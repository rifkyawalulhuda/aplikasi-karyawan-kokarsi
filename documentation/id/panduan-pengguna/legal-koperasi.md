# Legal Koperasi

Modul Legal Koperasi mengelola dokumen hukum dan ijin operasional koperasi.

## Mengakses Halaman

Klik **Dokumen Legal → Legal Koperasi** di sidebar.

## Kategori Dokumen

| Kategori | Keterangan |
|----------|-----------|
| **Izin** | Ijin usaha, ijin operasional |
| **Sertifikat** | Sertifikat legalitas |
| **Kebijakan** | Kebijakan internal koperasi |
| **Dokumen Internal** | Dokumen internal organisasi |
| **Dokumen B3** | Dokumen bahan berbahaya |
| **Lain-lain** | Dokumen lainnya |

## Tambah Dokumen

1. Klik **Tambah Dokumen**
2. Pilih kategori
3. Isi data dokumen:
   - Nama dokumen
   - Nomor dokumen
   - Penerbit
   - Tanggal dokumen
   - Apakah butuh perpanjangan?
   - Tanggal mulai & berakhir (jika butuh perpanjangan)
   - Lokasi dan keterangan
4. Upload file (opsional)
5. Klik **Simpan**

## Lihat Detail

Klik **⋮** → **Lihat Detail** untuk drawer detail yang menampilkan:
- Semua informasi dokumen
- Status & kategori badge
- Link dokumen lama (jika perpanjangan)
- Link ke dokumen baru (jika sudah diperpanjang)
- Preview dan download file

## Perpanjang Dokumen

Dokumen dengan status **Akan Berakhir** atau **Expired** dapat diperpanjang:

1. Klik **⋮** → **Perpanjang**
2. Field **Nama Dokumen** tidak dapat diubah (read-only)
3. Isi data baru: nomor dokumen, tanggal, dll.
4. Klik **Simpan**

Dokumen lama akan menampilkan link ke dokumen baru.

## Status Dokumen

| Status | Keterangan |
|--------|-----------|
| **Aktif** | Berlaku dan tidak akan habis dalam 30 hari |
| **Akan Berakhir** | Berakhir dalam ≤ 30 hari |
| **Expired** | Sudah berakhir |
| **Tidak Aktif** | Tidak butuh perpanjangan |
| **Sudah Diperpanjang** | Sudah diperpanjang dengan dokumen baru |

## Pencarian Global

Dokumen Legal Koperasi dapat ditemukan via pencarian global. Klik hasil pencarian untuk langsung membuka drawer detail dokumen tersebut.

## Notifikasi

Dokumen dengan `Butuh Perpanjangan = Ya` akan memicu notifikasi otomatis saat mendekati kadaluarsa. Lihat [Notifikasi](/panduan-pengguna/notifikasi).
