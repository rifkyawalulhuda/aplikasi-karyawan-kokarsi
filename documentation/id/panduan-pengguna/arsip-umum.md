# Arsip Umum

Modul Arsip Umum menyimpan dokumen umum koperasi beserta masa berlakunya, misalnya sertifikat, surat, atau dokumen pendukung lain yang tidak masuk kategori legal tertentu.

## Mengakses Halaman

Klik **Dokumen Legal → Arsip Umum** di sidebar.

## Daftar Arsip

Tabel menampilkan:

- **Dokumen** — nama dokumen disertai nomor dokumen (atau tulisan "Nomor tidak tersedia")
- **Tanggal Dibuat** — tanggal dokumen dibuat
- **Tanggal Berakhir** — tanggal berakhir; ditandai merah jika sudah lewat
- **Keterangan** — catatan tambahan
- **File** — tombol **Preview** untuk dokumen yang punya file

Di atas tabel ada kolom pencarian yang menyaring nama, nomor, dan keterangan sekaligus.

## Tambah Arsip

1. Klik **Tambah Arsip**
2. Isi formulir:
   - **Nama Dokumen** — wajib diisi
   - **Nomor Dokumen** — opsional
   - **Tanggal Dibuat** — opsional
   - **Tanggal Berakhir** — opsional
   - **Keterangan** — opsional
   - **File** — opsional, format PDF/JPG/PNG/WEBP maksimal 10MB
3. Klik **Simpan**

## Lihat Detail

Klik baris arsip, atau klik kanan lalu pilih **Lihat Detail**, untuk membuka drawer yang menampilkan:

- Nama dan nomor dokumen
- Badge status masa berlaku:
  - **Masih berlaku** — tanggal berakhir belum lewat
  - **Sudah berakhir** — tanggal berakhir sudah lewat
  - **Tanpa batas waktu** — tidak ada tanggal berakhir
- **Tanggal Dibuat** dan **Tanggal Berakhir**
- **Keterangan**
- Preview dan unduh file (PDF atau gambar)
- Metadata (tanggal dibuat/diperbarui)
- Tombol **Edit**

## Edit Arsip

1. Klik kanan pada baris → **Edit** (atau tombol Edit di drawer detail)
2. Ubah data yang diperlukan
3. Upload file baru jika ingin mengganti
4. Klik **Simpan**

## Hapus Arsip

1. Klik kanan pada baris → **Hapus**
2. Konfirmasi penghapusan

::: danger
Menghapus arsip bersifat permanen dan tidak dapat dikembalikan.
:::

## Export Excel

1. Klik **Export**
2. Pilih **Tahun Export**
3. Klik **Export Excel**

::: info
Arsip yang tidak punya **Tanggal Dibuat** hanya ikut ter-export pada opsi **Semua Tahun**.
:::

## Pencarian Global

Arsip Umum dapat ditemukan lewat pencarian global di header. Klik hasil pencarian untuk langsung membuka drawer detail arsip tersebut.
